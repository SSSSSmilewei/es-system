# Project Overview / 项目概览

Verda Ponto：世界语学习、知识收集、文献收集、爱好者交流、文化宣传一体化平台。

## 当前状态

- `index.html`：v0 前端原型，单文件、零依赖，包含首页（构词器）、学习、知识、文献、论坛、文化六个页面，数据硬编码或存于 localStorage。
- 尚无后端、构建工具和测试框架；技术栈将在首个 PRD 中确定。

## 文档约定（story skill）

- 需求：`docs/prd/<topic>.md`，修订用 `<topic>-v2.md`，旧版保留。
- 故事：`docs/story/<M>.<N>-<plan|wip|done>.md`。
- 调研与分析：`docs/research/`。

## 开发约定

- 界面文案以简体中文为主，世界语术语保留原文（含 ĉ ĝ ĥ ĵ ŝ ŭ）。
- 所有用户输入渲染前必须转义。
- 设计主色为世界语绿 `#009a44`，深色模式同步适配。
