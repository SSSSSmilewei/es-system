# Story 1.3 — 拆词与输入归一化

## 主要目标

实现 `analyze(word)`：把任意世界语词拆成词素序列，给出逐段释义和多候选排序。

## 验收标准

- [ ] 归一化：x 系统（`cx`）和 h 系统（`ch`，仅在不产生歧义时）转为带帽字母；统一小写。
- [ ] 识别屈折：复数 `-j`、宾格 `-n`、时态 `-as/-is/-os/-us/-u`、`-i`，并在结果中单独标出。
- [ ] 支持多个前缀、多个后缀以及复合词根（如 `lernolibro` = `lern + o + libr + o`）。
- [ ] 存在多种拆分时返回全部候选，按可信度排序（规则：官方词根优先、词素数更少优先、高频词根优先）。
- [ ] 无法拆分时返回明确的“未识别”结果和最长可识别片段。
- [ ] 公开 API 有完整类型定义；纯函数，无 I/O。
- [ ] 1000 个常见词的基准测试中单词平均耗时低于 1 毫秒。

## 功能要点

- 输出结构：词素列表（形式、类别、释义）、屈折信息、可信度、整体释义推断。
- 相关词（tabelvortoj，如 `kiu`、`tiam`）和虚词作为不可拆整体处理。

## 单元测试用例设计

- `malsanulejo` → `mal|san|ul|ej|o`。
- `sxatas` → `ŝat|as`（经 x 系统归一化）。
- `bonajn` → `bon|a`，屈折为复数 + 宾格。
- `lernolibro` → 复合词，两个词根。
- `kiu` → 相关词，不拆。
- 歧义词示例（如 `esperanto`：`esper|ant|o`）首选正确拆分。
- `xyzabc` → 未识别。

## 行为测试用例设计

- 用 200 个人工标注的词作为黄金集，首选拆分准确率不低于 95%，测试中输出错误列表。
