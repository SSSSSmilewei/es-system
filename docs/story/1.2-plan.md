# Story 1.2 — 词根数据格式与种子数据

## 主要目标

定义词根、词缀、词尾的数据格式，提供经过校验的种子数据，作为词法引擎的唯一数据来源。

## 验收标准

- [ ] `packages/morph/data/` 下有 `roots`、`prefixes`、`suffixes`、`endings` 数据文件（JSON 或 YAML）。
- [ ] 每个词根字段：词根、词性倾向（名 / 形 / 动）、中文释义、英文释义、词频等级（1–5）、来源、是否官方词根。
- [ ] 每个词缀字段：形式、类别（前缀 / 后缀）、语义、中英释义、示例词。
- [ ] 种子数据：全部官方前缀和后缀；至少 500 个高频词根，全部来自 Fundamento 或自编释义。
- [ ] `pnpm morph:validate` 校验脚本：字段齐全、无重复、只含合法字母、来源字段非空。
- [ ] 校验脚本纳入 CI。
- [ ] `docs/research/data-sources.md` 记录每个外部数据源的许可证结论。

## 功能要点

- 数据加载器在构建时把数据编译成按首字母索引的结构，供引擎快速前缀匹配。
- 词根与词缀可能同形（如 `ej` 也可作独立词根 `ejo`），数据中需能表达。

## 单元测试用例设计

- 校验器：缺少释义的条目报错并指出文件和行号。
- 校验器：含非法字符（如 `q`、`w`）的词根报错。
- 加载器：`san`、`lern` 可被查到；不存在的 `xyz` 返回空。

## 行为测试用例设计

- 在数据中故意加入重复词根，运行 `pnpm morph:validate`，命令以非零状态退出并列出重复项。
