# Story 5.1 — 论坛：版块、帖子、回复、通知

## 主要目标

把 v0 的本地假论坛变成真实的多用户论坛，帖子中的世界语词可点击拆解。

## 验收标准

- [ ] 版块：学习求助、翻译讨论、文化闲谈、活动组织、Esperanto-angulo（纯世界语区）；管理员可增删。
- [ ] 帖子：标题、正文（Markdown，限制可用语法）、版块、标签；作者可编辑（显示“已编辑”）和删除。
- [ ] 回复：支持引用回复；点赞；楼主可标记“最佳回答”（学习求助版块）。
- [ ] 帖子和回复正文使用阅读器组件渲染，世界语词可点击拆解。
- [ ] 通知：被回复、被引用、被 @ 提及、最佳回答；站内通知列表 + 可选邮件汇总。
- [ ] 列表排序：最新、最热（基于回复和点赞，随时间衰减）、未回复。
- [ ] 发帖与回复限流；新用户首帖需通过简单验证。
- [ ] 全部用户内容服务端过滤危险 HTML，前端转义输出。

## 功能要点

- 从 v0 迁移示例帖子时标注为示例，正式上线前清除。

## 单元测试用例设计

- Markdown 过滤：`<script>` 和 `javascript:` 链接被移除。
- 热度算法：同等互动下新帖排在旧帖前。
- @ 提及解析：`@用户名` 生成通知，不存在的用户名不生成。

## 行为测试用例设计

- 用户 A 发帖，用户 B 回复并 @ A，A 收到两条通知。
- 在帖子中点击世界语词弹出拆分卡片。
