# Story 2.3 — 判题引擎

## 主要目标

实现宽容而准确的答案判定，并对常见语法错误给出具体的中文提示。

## 验收标准

- [ ] 判定结果分三档：正确、几乎正确（显示正确写法）、错误。
- [ ] 忽略大小写、首尾空格、句末标点差异。
- [ ] 带帽字母可用 x 系统、h 系统或去帽形式输入：去帽形式判为“几乎正确”并提示正确字母。
- [ ] 单个非关键字母的拼写错误判为“几乎正确”；如果错误改变了语法（如漏掉 `-n`、`-j`）则判为错误。
- [ ] 语法提示（世界语答案）：漏宾格 `-n`、形容词与名词单复数或格不一致、时态词尾错误、缺少冠词 `la`。
- [ ] 中文答案接受同义表达（由题目提供多个正确答案）。
- [ ] 纯函数包 `packages/grader`，依赖 `packages/morph`。

## 功能要点

- 语法提示只在能确定时给出；无法确定时只显示正确答案，不猜测。

## 单元测试用例设计

- `Mi vidas la kato`（应为 `katon`）→ 错误，提示宾格。
- `bonaj amiko` → 错误，提示形容词与名词数不一致。
- `Mi sxatas` 对 `Mi ŝatas` → 正确。
- `Mi satas` 对 `Mi ŝatas` → 几乎正确，提示 ŝ。
- `Saluton!` 对 `saluton` → 正确。
- `Mi legis` 对 `Mi legas` → 错误，提示时态。
