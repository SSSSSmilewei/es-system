# Story 2.6 — FSRS 复习队列

## 主要目标

用 FSRS 算法安排复习，让学过的词根和错题在遗忘前回来。

## 验收标准

- [ ] 复习单位：词根卡（词根 + 代表派生词）和错题卡。
- [ ] 完成课时后，课时涉及的新词根自动加入复习队列；答错的题加入错题卡。
- [ ] 使用 ts-fsrs 计算下次复习时间；作答结果映射为评分（错误、几乎正确、正确、快速正确）。
- [ ] 复习页：今日待复习数量，复习时题型从已有题型中随机抽取，内容只来自该词根。
- [ ] 首页显示待复习数量徽标。
- [ ] 每日复习上限可设置（默认 100）。

## 功能要点

- 词根卡的题目由词法引擎和课程内容动态生成（如构词题、选择释义）。
- 复习也计入打卡和经验值。

## 单元测试用例设计

- 新卡首次正确后，下次复习时间晚于当前时间。
- 连续正确时间隔递增；一次错误后间隔缩短。
- 待复习数量不超过每日上限。

## 行为测试用例设计

- 完成一课后，模拟时间推进 1 天，复习页出现该课的词根卡，完成复习后数量减少。
