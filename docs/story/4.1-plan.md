# Story 4.1 — 文献库：数据模型、浏览与检索

## 主要目标

建立规范的书目数据模型，提供浏览、筛选和形态学检索。

## 验收标准

- [ ] 数据表：作品、人物（作者 / 译者，含生卒年）、作品与人物关系（角色）、出版版本（出版社、年份、ISBN、页数）、标签。
- [ ] 翻译作品可关联原作。
- [ ] 列表页：关键词搜索、按类型 / 年代 / 语言 / 标签筛选、按年份或标题排序、分页。
- [ ] 形态学检索：世界语关键词先经词法引擎取词根，匹配含相同词根的标题和简介。
- [ ] 作品详情页与人物详情页，服务端渲染、带结构化数据（schema.org Book、Person）。
- [ ] 从 v0 迁移 10 条示例书目，并补充到至少 50 条（附来源）。

## 功能要点

- 检索使用 PostgreSQL 全文检索 + 三元组模糊匹配；词根索引在写入时生成。

## 单元测试用例设计

- 形态学检索：搜 `lern` 命中标题含 `Lernolibro` 的作品。
- 筛选：类型“工具书” + 年代“1900–1950”只返回符合两者的条目。

## 行为测试用例设计

- 在文献页搜 `Zamenhof`，打开结果进入作品详情，点击作者进入人物页，列出其全部作品。
