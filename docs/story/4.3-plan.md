# Story 4.3 — 知识库：双语条目、版本历史、互链

## 主要目标

把知识库做成可协作编辑、有版本历史、条目互相关联的双语百科。

## 验收标准

- [ ] 条目：标题、主题、正文（Markdown）、语言版本（中 / 世）、引用来源列表。
- [ ] 登录用户可编辑；每次保存生成版本，可查看差异、回滚（编辑以上权限）。
- [ ] 互链语法：链接到其他条目、文献作品、词根，渲染为可点击链接；目标不存在时显示为红色待建链接。
- [ ] 条目页显示“链接到本条目的页面”。
- [ ] 历史事件条目带日期字段，供时间轴（5.3）使用。
- [ ] 从 v0 迁移 9 个条目，并补充引用来源。
- [ ] 搜索：全文检索 + 主题筛选。

## 功能要点

- 编辑冲突：保存时若基础版本已变化，提示用户合并而不是覆盖。

## 单元测试用例设计

- 互链解析：条目链接、文献链接、词根链接分别渲染为正确地址。
- 编辑冲突：两人基于同一版本编辑，后保存者收到冲突提示。

## 行为测试用例设计

- 编辑一个条目并保存，在历史页看到差异，回滚后内容恢复。
