# Story 1.1 — 工程骨架

## 主要目标

建立 pnpm monorepo 和 Next.js 应用骨架，让后续故事有统一的构建、测试、国际化和主题基础。

## 验收标准

- [ ] 目录结构：`apps/web`（Next.js App Router）、`packages/morph`（词法引擎，纯 TS，无框架依赖）。
- [ ] TypeScript strict 模式、ESLint、Prettier 配置完成，`pnpm lint` 和 `pnpm typecheck` 通过。
- [ ] Vitest 和 Playwright 可运行，各有一个示例测试通过。
- [ ] next-intl 接入，支持 `zh`、`en`、`eo` 三种语言路由，缺失文案回退到 `zh`。
- [ ] Tailwind 主题令牌沿用 v0 配色（世界语绿 `#009a44`），支持深色模式。
- [ ] 字体自托管（不依赖 Google Fonts 运行时加载），确认 ĉ ĝ ĥ ĵ ŝ ŭ 正常显示。
- [ ] GitHub Actions：每次推送运行 lint、typecheck、单元测试。
- [ ] 全站布局：顶部导航（首页、学习、词典、阅读、知识、文献、论坛、文化）、页脚、语言切换。
- [ ] v0 `index.html` 移至 `prototype/` 保留参考。

## 功能要点

- 导航中尚未实现的页面显示“建设中”占位页，而不是 404。
- 语言切换保留当前路径。
- 根 `README.md` 更新本地开发步骤。

## 单元测试用例设计

- 国际化：给定缺少 `en` 文案的键，返回 `zh` 文案。
- 主题：深色模式切换后根元素带对应属性。

## 行为测试用例设计

- 打开首页，导航所有链接均返回 200。
- 切换到 `eo` 后刷新页面，界面保持世界语。
- 在 390px 宽度下页面无横向滚动。
