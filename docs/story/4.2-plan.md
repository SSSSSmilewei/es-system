# Story 4.2 — 文献库：提交审核、版权状态、全文、引用导出

## 主要目标

让用户贡献书目，自动提示版权状态，公有领域作品开放全文阅读，并支持引用导出。

## 验收标准

- [ ] 登录用户可提交新书目，状态为“待审核”；编辑审核通过后发布，驳回需填写理由并通知提交者。
- [ ] 版权提示：根据全部作者和译者的卒年给出“可能已进入公有领域 / 仍受版权保护 / 无法判断”，并注明判断依据（年限按地区说明），提示仅供参考。
- [ ] 公有领域作品可由编辑上传全文（Markdown 或纯文本），全文页使用阅读器组件（3.3），支持章节目录。
- [ ] 引用导出：BibTeX、CSL-JSON，单条与批量（当前筛选结果）。
- [ ] 用户可收藏作品到个人书单。

## 功能要点

- 版权判断只做提示，不做法律结论；全文上传前编辑需勾选确认。

## 单元测试用例设计

- 版权：作者卒于 1917 年 → 可能已进入公有领域；卒于 2000 年 → 仍受保护；卒年未知 → 无法判断。
- BibTeX：含特殊字符（ĉ）的标题正确转义。

## 行为测试用例设计

- 用户提交书目，编辑在后台通过，列表中出现该条目。
- 打开公有领域作品全文，点击一个词弹出拆分卡片。
- 导出当前筛选结果为 BibTeX 文件，内容条目数与列表一致。
