# Story 3.1 — A1 内容补全、专项讲解与入学测试

## 主要目标

完成 A1 全部 8 个单元，加入针对中文母语者的专项讲解，并提供入学测试让有基础的人跳级。

## 验收标准

- [ ] 单元 3–8 内容：动词时态、宾格与语序、介词与方向、数字与时间、构词入门、相关词表入门；每单元 5 课时。
- [ ] 专项讲解卡：冠词 la、宾格 -n（含方向用法）、时态、形容词与名词一致、r 颤音与辅音丛发音；每张讲解卡附 3 道小练习。
- [ ] 每单元末尾一个单元测验，通过（80% 以上）才标记单元完成。
- [ ] 入学测试：自适应选题，最多 25 题，结果为可跳到的单元；用户确认后批量解锁之前的单元（不获得经验值）。
- [ ] 全部内容通过 `pnpm content:validate` 并经第二人审校。

## 功能要点

- 入学测试的题目从各单元测验题库中抽取，按难度逐步提升，连续答错 3 题即停止。

## 单元测试用例设计

- 自适应算法：全部答对时给出最高可跳单元；前 3 题全错时结果为单元 1。
- 单元测验：79% 不通过，80% 通过。

## 行为测试用例设计

- 新用户选择“我有基础”，完成入学测试后学习路径正确解锁。
- 打开宾格讲解卡，完成 3 道练习后返回课时。
