# Story 1.5 — 词典页与构词器页

## 主要目标

提供词典搜索、词条详情和构词器页面，让用户直接使用词法引擎。

## 验收标准

- [ ] 词典页：搜索框接受世界语或中文；世界语输入实时显示拆词结果；中文输入按释义匹配词根。
- [ ] 词条详情页（`/vortaro/[word]`）：拆分彩色展示、逐段释义、屈折说明、词族列表，可被搜索引擎收录（服务端渲染）。
- [ ] 构词器页：从 v0 迁移，词素选项来自种子数据，可搜索词根，可分享链接（组合编码在 URL 中）。
- [ ] 首页保留构词器入口和“今日词根”。
- [ ] 三种界面语言下文案完整。
- [ ] 键盘可完成全部操作；颜色区分之外还有文字标签区分词素类别。

## 功能要点

- 搜索输入防抖；引擎在浏览器端运行，无需请求服务器。
- 未识别时提示“可能是专有名词或新词”，并展示最长可识别片段。

## 单元测试用例设计

- 构词器 URL 编码与解码互为逆运算。
- 中文搜索“医院”返回 `malsanulejo`。

## 行为测试用例设计

- 在词典页输入 `malsanulejo`，看到五段拆分和释义“医院”。
- 输入 `cxokolado`，结果显示为 `ĉokolado`。
- 在构词器选择 lern + ej + o，结果为 `lernejo`，复制链接后在新页面打开得到相同组合。
- 访问 `/vortaro/lernejo`，页面源代码中已包含释义（服务端渲染）。
