# Story 3.3 — 阅读器：可点击拆词与生词收藏

## 主要目标

做一个通用阅读组件：任何世界语文本中的词都可点击，显示拆分和释义，并可收藏到复习队列。

## 验收标准

- [ ] 阅读组件：输入纯文本或 Markdown，分词后每个世界语词可点击 / 可聚焦。
- [ ] 点击弹出卡片：词形、拆分（彩色）、逐段释义、屈折说明、播放发音、“加入复习”按钮。
- [ ] 已掌握词根的词默认不加下划线，生词加细下划线（可在设置中关闭）。
- [ ] 文章页 `/legi/[slug]`：标题、作者、来源、许可证、正文。
- [ ] 文章内容以 Markdown 文件维护，附元数据（等级、标签、来源、许可证）。
- [ ] 首批 10 篇公有领域或自编短文。
- [ ] 阅读组件同时用于论坛帖子（5.1）和文献全文（4.2），作为公共组件导出。

## 功能要点

- 分词需处理标点、引号、连字符、数字和专有名词（大写开头且无法拆分的词不标为生词）。
- 弹出卡片在手机上以底部抽屉形式出现。

## 单元测试用例设计

- 分词：`"Saluton," diris ŝi.` 得到 `Saluton`、`diris`、`ŝi` 三个可点击词。
- 生词标记：已掌握 `lern` 时，`lernejo` 不标为生词。

## 行为测试用例设计

- 打开一篇文章，点击 `malsanulejo`，看到拆分卡片，点“加入复习”后复习页数量 +1。
- 只用键盘在文章中切换词并打开卡片。
