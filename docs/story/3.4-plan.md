# Story 3.4 — 分级读物与覆盖率推荐

## 主要目标

根据每个用户已掌握的词根，计算文章覆盖率，推荐“刚好能读懂”的文章。

## 验收标准

- [ ] 文章构建时预计算所含词根集合和每个词根出现次数。
- [ ] 用户覆盖率 = 文章中已掌握词根的词次占比，在文章列表中显示。
- [ ] 阅读页列表：按推荐（覆盖率 90%–98% 优先）、等级、标签筛选。
- [ ] 学习路径中每个单元结束后推荐 1 篇读物。
- [ ] 访客按所选等级显示估计覆盖率。

## 功能要点

- “已掌握”定义：词根在复习队列中稳定度超过阈值，或已在课程中学过。

## 单元测试用例设计

- 文章 100 个词次，其中 92 个词根已掌握 → 覆盖率 92%。
- 推荐排序：92% 的文章排在 70% 和 100% 之前。

## 行为测试用例设计

- 完成单元 1 后，阅读页首位推荐的文章覆盖率在 90% 以上。
