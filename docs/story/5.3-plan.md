# Story 5.3 — 活动、日历与历史时间轴

## 主要目标

支持各地小组发布活动、用户报名，并由知识库数据生成历史时间轴。

## 验收标准

- [ ] 活动：标题、简介、开始 / 结束时间（含时区）、线上链接或线下地点、主办方、人数上限、语言要求。
- [ ] 小组：城市 / 线上小组主页，组织者可发布活动。
- [ ] 报名与取消；满员后进入候补；活动前 24 小时邮件提醒。
- [ ] 活动列表与月历视图，按城市 / 线上筛选；时间按查看者时区显示。
- [ ] 导出 iCal（单个活动和订阅链接）。
- [ ] 历史时间轴页：从知识库事件条目生成，按真实时间比例绘制（沿用 v0 设计），点击事件进入条目。

## 单元测试用例设计

- 时区：UTC 12:00 的活动对 UTC+8 用户显示 20:00。
- 候补：满员后报名进入候补；有人取消时候补第一位转正并收到通知。
- iCal：生成内容通过格式校验。

## 行为测试用例设计

- 组织者发布活动，用户报名，活动详情显示已报名人数。
- 时间轴页点击 1887 年事件，进入对应知识条目。
