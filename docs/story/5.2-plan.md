# Story 5.2 — 举报审核与个人主页

## 主要目标

提供社区自治工具，并让每个用户有展示学习和贡献的主页。

## 验收标准

- [ ] 任何帖子、回复、知识条目修改、文献提交都可被举报（理由分类 + 说明）。
- [ ] 版主审核队列：查看举报、隐藏内容、警告用户、临时禁言、驳回举报；所有操作记录审计日志。
- [ ] 被处理的用户收到通知和理由。
- [ ] 个人主页 `/u/[name]`：头像、简介、连续打卡、已学词根数、等级、论坛帖子、知识编辑、文献贡献。
- [ ] 隐私设置：可隐藏学习数据。
- [ ] 贡献徽章：首次编辑知识条目、首个最佳回答等（原创图标）。

## 单元测试用例设计

- 禁言用户无法发帖，禁言到期后恢复。
- 隐藏学习数据后，他人访问主页不返回这些字段。

## 行为测试用例设计

- 用户举报一条回复，版主在队列中隐藏它，帖子中该回复显示“已被隐藏”。
