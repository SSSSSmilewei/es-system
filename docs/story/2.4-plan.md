# Story 2.4 — 课时播放器与题型

## 主要目标

做出完整的答题界面：逐题推进、即时反馈、课时结算。

## 验收标准

- [ ] 课时播放器：进度条、题目区、答题区、底部检查按钮和反馈条；答错的题在本课末尾重做一次。
- [ ] 实现题型：选择释义、选择翻译、词块拼句（点选与拖拽皆可）、键入翻译、配对、构词。
- [ ] 听音选择与听写：先用浏览器语音合成（若无世界语语音则隐藏此题型并跳过），正式语音方案在 3.2 实现。
- [ ] 键入题提供带帽字母快捷按钮（ĉ ĝ ĥ ĵ ŝ ŭ）。
- [ ] 反馈条展示判题结果、正确答案、语法提示和讲解。
- [ ] 课时结算页：正确率、获得经验值、用时、星级（1–3 星）。
- [ ] 中途退出需确认；刷新页面可从当前题继续。
- [ ] 手机上全部题型单手可操作，按钮至少 44px；全部题型可键盘操作；尊重“减少动态效果”设置。
- [ ] 原创视觉：以绿星为元素的庆祝动画和吉祥物（原创形象）。

## 功能要点

- 播放器只依赖编译后的课时 JSON 和判题包，可在无账号状态下运行。
- 每次作答记录（题目 ID、结果、用时）交给 2.5 和 2.6 处理。

## 单元测试用例设计

- 题目队列：答错 2 题时，课末追加这 2 题。
- 星级计算：正确率 100% 为 3 星，80% 以上为 2 星，其余 1 星。
- 恢复：保存的进度在刷新后恢复到同一题。

## 行为测试用例设计

- 完整玩一课：全部答对，结算页显示 3 星。
- 词块拼句：按错误顺序提交，看到错误反馈和正确句子。
- 在 390px 宽度下完成一节课，无横向滚动。
- 只用键盘完成一个配对题。
