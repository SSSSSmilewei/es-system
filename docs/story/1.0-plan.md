# Story 1.0 — M1 概览：工程骨架、词法引擎与词典

来源：`docs/prd/verda-ponto.md` 第 4.1、6、7 节。

## 范围

搭建 TypeScript monorepo，实现全站共用的词法引擎（拆词、组词、词族、输入容错）和词典 / 构词器页面。本里程碑不含账号和数据库。

## 子故事与依赖

| 故事 | 标题 | 依赖 |
| --- | --- | --- |
| 1.1 | 工程骨架 | 无 |
| 1.2 | 词根数据格式与种子数据 | 1.1 |
| 1.3 | 拆词与输入归一化 | 1.2 |
| 1.4 | 组词与词族 | 1.2（可与 1.3 并行） |
| 1.5 | 词典页与构词器页 | 1.3、1.4 |

## 里程碑完成标准

- 网站可本地运行，词典页可拆任意常见词，构词器从 v0 迁移完成。
- `packages/morph` 单元测试覆盖率 90% 以上。

## 全局风险

- 词根数据许可证未核实前，只使用 Fundamento（公有领域）和自编数据。
