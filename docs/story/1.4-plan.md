# Story 1.4 — 组词与词族

## 主要目标

实现 `compose(parts)` 和 `family(root)`，为构词器和词族展示提供数据。

## 验收标准

- [ ] `compose`：输入前缀列表、词根、后缀列表、词尾，输出词形、彩色分段信息、释义推断。
- [ ] 若组合结果是词典中的常用词，标记“常用词”并给出词典释义；否则标记“合乎规则的新组合”。
- [ ] 对语义上不常见的组合给出提示（如给形容词性词根加 `-in-`）。
- [ ] `family(root)`：返回该词根常见派生词，按词频排序，每个附拆分和释义。
- [ ] 种子数据中提供至少 100 个“常用派生词”条目用于标记和词族展示。

## 功能要点

- `compose` 与 `analyze` 互为逆运算：对常用词，`analyze(compose(x))` 的首选结果等于 x。

## 单元测试用例设计

- `compose(mal, san, ul, ej, o)` → `malsanulejo`，常用词“医院”。
- `compose(lern, ej, o)` → `lernejo`。
- `family(lern)` 包含 `lerni`、`lernejo`、`lernanto`、`lernolibro`。
- 往返测试：对全部常用派生词执行 compose → analyze，首选结果一致。
