# Story 2.2 — 课程内容格式、校验与前 2 单元内容

## 主要目标

定义可版本化、可审阅的课程内容格式，编写 A1 单元 1–2 的内容，并用脚本保证内容正确。

## 验收标准

- [ ] 内容目录 `content/courses/zh-eo/`：课程 → 单元 → 课时，每课时一个 YAML 文件。
- [ ] 题目字段：题型、题干、正确答案（可多个）、干扰项、讲解、涉及词根、音频文本。
- [ ] 支持的题型标识：选择释义、选择翻译、词块拼句、键入翻译、听音选择、听写、配对、构词。
- [ ] 每个单元可附“讲解卡”（如冠词 la、宾格 -n），在课时开始前展示。
- [ ] 校验脚本 `pnpm content:validate`：结构合法；所有世界语答案经词法引擎可识别；涉及词根存在于词根数据；词块拼句的词块能拼出正确答案。
- [ ] 单元 1（问候与自我介绍）、单元 2（名词、形容词、复数）各 5 课时，每课时 12–15 题。
- [ ] 内容由第二人审校后合入（在 PR 模板中加入审校勾选项）。

## 功能要点

- 内容文件构建时编译为 JSON，前端按课时懒加载。
- 题目 ID 稳定，修改内容不影响用户已有的复习记录。

## 单元测试用例设计

- 校验器：答案含未识别词时报错并指出文件与题目 ID。
- 校验器：词块无法拼出答案时报错。
- 编译器：输出 JSON 与 YAML 的题目数一致。

## 行为测试用例设计

- 在 CI 中运行内容校验，故意引入错误的分支应失败。
