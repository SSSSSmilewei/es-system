# Story 2.0 — M2 概览：账号与零基础学习系统核心

来源：`docs/prd/verda-ponto.md` 第 4.2、4.8 节。

## 范围

接入数据库和账号，完成游戏化学习系统的核心：课程内容格式、判题、课时播放器、学习路径与激励、间隔重复复习。交付时 A1 前 2 个单元可完整游玩。

## 子故事与依赖

| 故事 | 标题 | 依赖 |
| --- | --- | --- |
| 2.1 | 数据库与账号 | 1.1 |
| 2.2 | 课程内容格式、校验与前 2 单元内容 | 1.2 |
| 2.3 | 判题引擎 | 1.3 |
| 2.4 | 课时播放器与题型 | 2.2、2.3 |
| 2.5 | 学习路径、经验值、每日目标、连续打卡 | 2.1、2.4 |
| 2.6 | FSRS 复习队列 | 2.1、2.4 |

## 里程碑完成标准

- 新用户注册后可从单元 1 课时 1 玩到单元 2 结束，进度、经验值、打卡跨设备同步。
- 未登录用户可试玩单元 1 课时 1，结束时引导注册并保留本次进度。

## 设计约束

- 借鉴通用游戏化机制，视觉风格、吉祥物、文案全部原创，不复制任何现有产品的外观和角色。
- 不做惩罚性“体力”机制，答错只影响本课星级。
