# Story 3.2 — 语音合成与听力题

## 主要目标

为所有世界语内容提供可接受质量的发音，正式启用听音选择、听写题。

## 验收标准

- [ ] 方案评估：对比 eSpeak NG 和至少一个支持世界语的云端语音服务（音质、成本、许可证），结论写入 `docs/research/tts.md`。
- [ ] 构建时为课程内容批量生成音频文件并缓存（按文本哈希命名），不在用户请求时实时合成。
- [ ] 所有世界语题干、讲解例句、词典词条可点击播放。
- [ ] 听音选择、听写题对全部用户开放；播放器支持慢速播放。
- [ ] 无音频时题型自动降级为文字题，不阻塞学习。
- [ ] 设置中可关闭听力题（如在公共场所）。

## 功能要点

- 世界语一字一音，可在词典页展示音节划分和重音位置（倒数第二音节）。

## 单元测试用例设计

- 音节划分：`familio` → `fa-mi-li-o`，重音在 `li`。
- 音频缓存键：相同文本得到相同文件名。

## 行为测试用例设计

- 在课时中完成一道听写题，慢速播放按钮可用。
- 关闭听力题后，课时中不再出现听力题。
