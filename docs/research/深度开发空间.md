# Verda Ponto 深度开发空间分析

> 基于 v0 Demo（单文件前端原型）的自主复盘。目的是为后续 PRD 提供素材和决策点，不是最终需求。

## 0. 一句话结论

现在的 Demo 是“五个并列模块的外壳”。真正能拉开差距的，是把 **世界语的构词规律** 做成一个贯穿全站的核心引擎：
学习、阅读、论坛、文献检索都建立在“任何一个词都能被拆开、解释、关联”之上。这是其他语言平台做不到、而世界语天然适合的事情。

## 1. Demo 现状与局限

| 模块 | 现在是什么 | 主要局限 |
| --- | --- | --- |
| 构词器 | 8 个词根 × 固定词缀，查 40 个词的小词典 | 不能输入任意词；不能反向拆词 |
| 闪卡 | 16 个词，“记住 / 再看”二元记录 | 没有间隔重复算法，没有词频体系 |
| 课程 | 静态进度条 | 没有真实课程内容、练习和测评 |
| 知识库 | 9 条硬编码条目 | 不能编辑，没有引用来源和版本 |
| 文献库 | 10 条书目 | 没有元数据标准、全文、版权状态 |
| 论坛 | localStorage 假数据 | 没有账号、审核、通知 |
| 文化 | 时间轴 + 示例活动 | 没有活动报名、内容运营工具 |
| 技术 | 单 HTML 文件 | 无后端；Google Fonts 在中国大陆访问不稳定 |

## 2. 核心引擎：词法分析（最值得投入）

世界语的派生是完全规则的：`前缀* + 词根 + 后缀* + 词尾`。只要有一份可靠的词根表，就能对绝大多数词做自动拆分。

- **数据来源**：Fundamento 词根、官方词根表（Baza Radikaro Oficiala）、开放词典 ReVo（Reta Vortaro，需核对许可证）。
- **能力**：
  - 正向：组词并给出释义推断（Demo 已有雏形）。
  - 反向：输入 `malsanulejo` → `mal|san|ul|ej|o`，逐段解释；对歧义拆分给出候选及置信度。
  - 词族：`lern-` 一键列出 lerni / lernejo / lernanto / lernolibro……
- **被谁复用**：
  - 阅读器：任何文章点词即拆。
  - 论坛：帖子里的世界语词自动可点。
  - 文献检索：搜 `lern` 能命中所有派生词（形态学检索）。
  - 学习：按“词根”而不是“单词”记忆，学 1 个词根解锁一族词。

## 3. 学习：从展示到真正有效

1. **间隔重复**：用 FSRS 等算法替换二元记录；卡片单位是“词根 + 代表派生词”。
2. **词频驱动**：基于语料（如 Tekstaro）给词根排频率，先学高频 500 根。
3. **分级读物**：每篇文章计算“已掌握词根覆盖率”，只推荐覆盖率 90% 以上的。
4. **语法检查**：规则可确定地实现（形容词与名词的数、格一致，-n 遗漏，冠词），即时纠错。
5. **AI 陪练**：对话练习 + 纠错解释；规则检查器兜底，降低模型出错的影响。
6. **发音**：世界语一字一音，TTS 和跟读评分都容易做；针对中文母语者的难点（r 颤音、辅音丛、ĥ）。
7. **考试对齐**：对接按 CEFR 分级的 KER 考试，提供 B1/B2 模拟题。
8. **中文母语者专项**：宾格、冠词、时态这些汉语里没有的概念，单独设计讲解和练习。

## 4. 知识库：从条目到知识图谱

- 维基式协作编辑，带版本历史、引用来源、审核流程。
- 中文 / 世界语双语条目，互相链接。
- 实体化：人物、作品、组织、事件、地点之间建立关系，时间轴和地图从同一份数据生成。

## 5. 文献库：最有长期价值、也最有研究意义

- **规范元数据**：作者、译者、原作、语言、出版地、ISBN、馆藏，可导出 BibTeX / CSL。
- **全文与扫描件**：老文献 OCR，带帽字母常被识别错，可用词法引擎做后校正。
- **版权状态**：根据作者卒年自动判断公有领域，公有领域作品开放全文阅读。
- **中文—世界语平行语料**：如《中国报道》历年文章、中国古典作品译本，按句对齐，对翻译者和研究者都有价值。
- **外部对接**：古腾堡计划的世界语文本、各地世界语图书馆目录。

## 6. 社区：让人留下来

- 账号与成长：学习数据、贡献（编辑、翻译、回答）都计入个人主页。
- 结对互助：新手和有经验的世界语者配对。
- 地方小组：各城市协会主页、活动发布、报名、签到。
- 众包翻译：把“文献库”和“社区”连起来，例如共同翻译一部中文作品，分段认领、互审、发布进文献库。
- 内容审核：举报、版主、敏感词（面向国内上线必须有）。

## 7. 文化宣传：对外的出口

- 分享卡片：今日词汇、名句、活动海报一键生成图片，适配微信 / 小红书。
- 节点运营：柴门霍夫日（12/15）、世界语诞生日（7/26）专题页。
- 新闻简报 / 公众号同步。

## 8. 技术与上线方向的关键分叉

| 决策 | 选项 | 影响 |
| --- | --- | --- |
| 目标用户 | 中文学习者为主 / 国际用户为主 | 决定界面语言、内容来源、部署地区 |
| 部署地区 | 中国大陆（需 ICP 备案、国内 CDN、字体本地化） / 海外 | 决定登录方式（微信 vs 邮箱）、合规工作量 |
| 端 | Web + PWA / 微信小程序 / 原生 App | 小程序获客快，Web 适合知识库和文献 |
| 内容来源 | 自建团队 / 社区共建 / 授权引进 | 决定编辑审核系统的复杂度 |
| AI 功能 | 不做 / 辅助 / 核心卖点 | 决定成本模型 |

## 9. 建议的路线（供讨论）

1. **M1 词法引擎 + 词典**：先做核心，其他模块都依赖它。
2. **M2 学习闭环**：账号、间隔重复、分级阅读器（复用引擎）。
3. **M3 文献库正式化**：元数据、检索、公有领域全文。
4. **M4 社区与众包翻译**。
5. **M5 宣传工具与运营后台**。
