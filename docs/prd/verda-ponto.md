# PRD：Verda Ponto 世界语综合平台 v1

> 状态：草稿，由 Claude 根据 v0 Demo、`docs/research/深度开发空间.md` 和产品负责人的决策起草，待产品负责人审阅修改。

## 1. 背景与定位

世界语有规则、无例外的构词系统，却缺少一个把“学习、阅读、文献、社区、文化”连起来的现代平台。主流语言学习应用目前没有面向中文母语者的世界语课程。

**定位**：面向全球的世界语综合平台，以中文母语者的零基础课程为切入点，同时服务已有基础的世界语者和研究者、译者。

## 2. 已确定的决策

| 项 | 决策 |
| --- | --- |
| 目标用户 | 三类兼顾：零基础学习者、已有基础的世界语者、研究者与译者 |
| 部署 | 海外 / 国际；无需 ICP 备案；登录用邮箱与第三方账号 |
| 范围 | 全部模块都做，按里程碑交付 |
| 新增重点 | 游戏化的零基础学习系统，借鉴通用玩法，视觉与角色完全原创 |
| 团队 | 个人 / 小团队，技术栈由开发方选定 |

## 3. 用户与核心场景

1. **零基础学习者**（中文母语）：每天 5–15 分钟闯关，坚持打卡，三个月读懂简单短文。
2. **世界语者**：读文章遇到生词点一下就拆解；在论坛交流；参加活动。
3. **研究者与译者**：检索书目、阅读公有领域全文、查中文—世界语平行句对、导出引用。

## 4. 功能需求

### 4.1 词法引擎（基础设施，所有模块共用）

- F1 拆词：输入任意世界语词，输出 `前缀* + 词根(可复合) + 后缀* + 词尾` 的拆分，逐段中文 / 英文释义；多种拆分时按可信度排序。
- F2 组词：选择词素生成词，并给出释义推断（v0 构词器的正式版）。
- F3 词族：给定词根，列出常见派生词。
- F4 输入容错：x 系统（cx）和 h 系统（ch）自动转为带帽字母；大小写和词尾变化（-j、-n、时态）归一化。
- F5 词根数据：以 Fundamento 和官方词根表为核心，附中英释义与词频等级；数据来源许可证需核实后再导入。

### 4.2 零基础学习系统（游戏化）

- L1 学习路径：课程 → 单元 → 课时，线性解锁；首期内容为 A1（约 8 单元 × 5 课时）。
- L2 题型：
  - 选择释义 / 选择翻译
  - 词块拼句（把打乱的词排成句子）
  - 键入翻译（世界语 ↔ 中文）
  - 听音选择 / 听写
  - 配对（词与释义连线）
  - 构词题（世界语特有：用词素拼出目标词）
  - 跟读（v1 可选，依赖语音识别可用性）
- L3 判题：接受多种正确答案；带帽字母可用 x / h 系统输入；轻微拼写错误判为“几乎正确”；针对语法错误给出具体提示（如“这里是直接宾语，需要加 -n”）。
- L4 激励：经验值、每日目标、连续打卡、课时完成星级；不做付费或惩罚性的“体力”机制。
- L5 复习：错题和学过的词根进入间隔重复队列（FSRS 算法），首页提示今日待复习数量。
- L6 入学测试：有基础的用户可通过测试跳过前面的单元。
- L7 课程内容以结构化文件维护（版本化、可审阅），并提供内容校验脚本。
- L8 中文母语者专项讲解：冠词 la、宾格 -n、时态、形容词与名词一致、r 颤音和辅音丛发音。

### 4.3 阅读器与分级读物

- R1 文章阅读：任意世界语词可点击，弹出拆词和释义（复用 F1）。
- R2 难度标注：按用户已掌握词根计算覆盖率，推荐覆盖率高的文章。
- R3 生词收藏：一键加入复习队列。

### 4.4 知识库

- K1 双语条目，主题分类、全文搜索。
- K2 登录用户可编辑，保留版本历史，可回滚；条目可附引用来源。
- K3 条目之间、条目与文献和词根之间可互相链接。

### 4.5 文献库

- B1 书目：标题、作者、译者、原作、语言、年份、类型、出版信息、ISBN、简介、标签。
- B2 检索：关键词 + 筛选 + 形态学检索（搜 `lern` 命中派生词）。
- B3 版权状态：根据作者卒年给出是否进入公有领域的提示；公有领域作品可上传并在线阅读全文（全文接入阅读器）。
- B4 引用导出：BibTeX、CSL-JSON。
- B5 平行语料（v1 后段）：中文—世界语句对，按句对齐展示和检索。
- B6 用户提交条目，经审核后发布。

### 4.6 社区论坛

- C1 版块、帖子、回复、点赞、通知。
- C2 帖子中的世界语词可点击拆解（复用 F1）。
- C3 举报与版主处理。
- C4 个人主页：学习数据、贡献记录。

### 4.7 文化与活动

- E1 活动发布、报名、日历视图、线上 / 线下标记。
- E2 历史时间轴，由知识库中的事件数据生成。
- E3 分享卡片：今日词汇、名句、活动海报生成图片。
- E4 纪念日专题页（如 12 月 15 日柴门霍夫日）。

### 4.8 账号与通用

- A1 邮箱登录 + Google / GitHub 第三方登录。
- A2 角色：访客、用户、编辑、版主、管理员。
- A3 界面语言：中文、英文、世界语。
- A4 深色模式；手机优先；可安装到桌面（PWA）。

## 5. 非功能需求

- 性能：首页首屏在 4G 网络下 2.5 秒内可交互。
- 可访问性：满足 WCAG 2.1 AA 主要条款；所有题型可键盘操作。
- 安全：所有用户内容转义输出；基础限流；敏感操作需登录。
- 数据：用户可导出和删除自己的数据。

## 6. 技术方案（建议）

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 语言 | TypeScript 全栈 | 一种语言，前后端共享类型 |
| 仓库 | pnpm monorepo | 词法引擎作为独立包，前后端复用 |
| Web | Next.js（App Router）+ Tailwind CSS | 主流、SEO 友好（知识库、文献需要被搜索引擎收录） |
| 数据库 | PostgreSQL + Drizzle ORM | 关系数据为主，自带全文检索和三元组模糊匹配 |
| 认证 | Auth.js | 支持邮箱链接和第三方登录 |
| 间隔重复 | ts-fsrs | 成熟的 FSRS 实现 |
| 国际化 | next-intl | 中 / 英 / 世界语 |
| 测试 | Vitest（单元）+ Playwright（端到端） | |
| 部署 | Vercel + 托管 PostgreSQL（如 Neon） | 小团队运维成本低 |
