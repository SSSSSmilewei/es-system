# Verda Ponto · 世界语学习与交流平台（Demo）

一个现代化的世界语综合平台前端演示，单文件、零依赖，直接用浏览器打开 `index.html` 即可。

## 模块

| 模块 | 内容 |
| --- | --- |
| 首页 Hejmo | 交互式构词器（前缀 + 词根 + 后缀 + 词尾）、今日词汇、近期活动、论坛热帖 |
| 学习 Lerni | 翻转闪卡（记录掌握进度）、分级课程路径、词尾速查表、x 系统输入转换（cx → ĉ） |
| 知识 Scio | 语法、历史、人物、社群条目，支持搜索和主题筛选，弹窗阅读全文 |
| 文献 Biblioteko | 书目库（原创、译作、工具书、教材、期刊），可筛选、排序、添加条目 |
| 论坛 Forumo | 分版块帖子列表、展开回复、发帖与回帖 |
| 文化 Kulturo | 按真实时间比例的历史时间轴、活动日历、会歌 La Espero、绿星含义 |

## 说明

- 论坛帖子、活动、用户名为示例内容；新增的帖子、文献和学习进度只保存在浏览器 localStorage 中。
- 后续若做成正式系统，可拆分为前端（Vue/React）+ 后端 API（用户、帖子、文献、词库）+ 数据库。
